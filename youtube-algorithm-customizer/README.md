# 🎯 FocusTube — YouTube 알고리즘 커스터마이저

유튜브 홈 피드를 **내가 정한 주제**(예: 수험생 공부 자극)로 교체하고,
기존 알고리즘의 **초기화 → 재학습**을 도와주는 크롬 확장프로그램입니다.

## 왜 이런 방식인가? (실현 방안)

유튜브 추천 알고리즘은 구글 서버 내부에서 동작하며, 이를 외부에서 직접
수정하거나 초기화하는 공식 API는 존재하지 않습니다. 하지만 알고리즘은
**시청 기록 · 검색 기록 · 좋아요/구독** 등 사용자의 행동 데이터로 학습되므로,
그 입력을 통제하면 사실상 원하는 방향으로 알고리즘을 바꿀 수 있습니다.

FocusTube는 이를 3단계 전략으로 구현합니다.

| 단계 | 내용 | 구현 방식 |
|------|------|-----------|
| ① 초기화 | 기존 시청·검색 기록 삭제 | 구글 「내 활동」·유튜브 기록 관리 페이지 바로가기 제공 |
| ② 피드 교체 | 홈 화면을 원하는 주제의 영상으로 교체 | 콘텐츠 스크립트가 기존 추천 그리드를 숨기고, 선택한 키워드의 검색 결과로 새 피드를 렌더링 |
| ③ 재학습 | 알고리즘을 원하는 방향으로 훈련 | 교체된 피드의 영상을 시청하면 시청 기록이 해당 주제로만 쌓여, 유튜브 알고리즘이 자연스럽게 그 주제를 학습 |

즉, **알고리즘이 학습되는 동안에도 사용자는 이미 원하는 피드를 보게 되고**,
시청을 거듭할수록 실제 유튜브 추천도 그 방향으로 수렴합니다.

### 동작 원리 (기술)

- **홈 피드 교체**: `www.youtube.com` 홈에서 기존 추천 그리드
  (`ytd-two-column-browse-results-renderer`)를 CSS로 숨기고, 선택된 프리셋의
  키워드 중 3개를 무작위로 골라 유튜브 검색 결과 페이지를 같은 출처(fetch)로
  받아 `ytInitialData` JSON을 파싱한 뒤, 영상 카드를 직접 렌더링합니다.
  외부 API 키가 필요 없습니다.
- **캐시**: 검색 결과는 30분간 `sessionStorage`에 캐시되며,
  「새로고침」 버튼으로 다른 키워드 조합을 즉시 불러올 수 있습니다.
- **SPA 대응**: 유튜브의 `yt-navigate-finish` 이벤트를 감지해 페이지 이동
  시에도 피드를 유지합니다.
- **집중 옵션**: Shorts / 시청 중 사이드바 추천 / 댓글을 CSS로 숨길 수
  있습니다 (딴길로 새는 것 방지).
- **설정 동기화**: 모든 설정은 `chrome.storage.sync`에 저장되어 같은 구글
  계정의 다른 PC에서도 유지됩니다.

## 설치 방법

1. 이 폴더(`youtube-algorithm-customizer/`)를 PC에 내려받습니다.
2. 크롬 주소창에 `chrome://extensions` 입력 → 우측 상단 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드** 클릭 → 이 폴더 선택.
4. youtube.com 접속 → 홈 화면이 선택한 주제의 피드로 바뀝니다.
5. 툴바의 🎯 아이콘을 눌러 주제·옵션을 변경할 수 있습니다.

> 아이콘 PNG는 저장소에 포함되어 있습니다. 다시 생성하려면
> `python3 tools/make_icons.py`를 실행하세요.

## 사용법 — 수험생 모드 예시

1. 팝업에서 **「수험생 · 공부 자극」** 프리셋 선택 (기본값).
2. 「알고리즘 초기화」 섹션의 링크에서 기존 시청·검색 기록 삭제.
3. 새 홈 피드에 뜨는 공부 자극 / study with me / 공부법 영상을 시청.
4. 며칠 시청하면 실제 유튜브 추천(모바일 앱 포함)도 공부 영상 위주로 바뀝니다.
5. 더 빠르게 바꾸려면: 다른 주제 영상에서 ⋮ → **「관심 없음」**,
   채널 단위로는 **「채널 추천 안함」**을 눌러 주세요.

「사용자 정의」 프리셋을 선택하면 원하는 검색 키워드를 한 줄에 하나씩 직접
입력할 수 있습니다.

## 프로젝트 구조

```
youtube-algorithm-customizer/
├── manifest.json        # 확장프로그램 정의 (Manifest V3)
├── common/presets.js    # 주제 프리셋 (콘텐츠 스크립트·팝업 공용)
├── content/feed.js      # 홈 피드 교체 + 검색 결과 파싱
├── content/feed.css     # 피드 스타일 + Shorts/추천/댓글 숨김
├── popup/               # 설정 팝업 (주제·옵션 선택, 초기화 바로가기)
├── icons/               # 확장 아이콘 (생성 결과물)
└── tools/make_icons.py  # 아이콘 생성 스크립트 (의존성 없음)
```

## 한계와 주의사항

- 본인 계정의 시청 환경을 스스로 관리하는 **개인용 도구**입니다.
- 유튜브 페이지 구조(`ytInitialData` 등)가 변경되면 피드 로딩이 실패할 수
  있습니다. 이 경우 「새로고침」을 누르거나 셀렉터를 업데이트해야 합니다.
- 모바일 유튜브 앱의 화면은 바꿀 수 없지만, ③ 재학습이 진행되면 같은 계정의
  모바일 추천도 함께 바뀝니다 (알고리즘은 계정 단위로 학습되기 때문).
- 시청 기록을 「일시중지」하면 알고리즘이 재학습되지 않으니, 재학습 단계에서는
  기록을 켜 두어야 합니다.
